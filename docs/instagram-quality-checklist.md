# چک‌لیست کیفیت تصاویر استودیو اینستاگرام

هر تصویر تولیدشده پیش از انتشار باید بازبینی شود. تولید تصویر با هوش مصنوعی قطعی نیست و ممکن است رنگ، طرح یا جزئیات لباس را تغییر دهد.

## مجموعه ارزیابی ثابت

برای مقایسه منصفانه نسخه‌های پرامپت، این نمونه‌ها را همیشه نگه دارید و روی هر تغییر پرامپت دوباره بررسی کنید:

| نمونه | چیزی که ثابت می‌کند |
|---|---|
| لباس روشن | حفظ رنگ روشن و جزئیات روی زمینه روشن |
| لباس تیره | حفظ رنگ تیره، بافت و لبه‌ها |
| لباس طرح‌دار | جای دقیق چاپ، راه‌راه، گل یا نوشته |
| لباس با جزئیات ریز | دکمه، زیپ، گلدوزی، درز و ترمه |
| محصول چندرنگ | انتخاب درست همان رنگ/تنوع و نه رنگ دیگر |
| مرجع جلو/پشت/جزئیات | استفاده درست از تصویر اصلی، پشت و نمای نزدیک |

## معیارهای بازبینی

- [ ] رنگ دقیقاً با تصویر مرجع یکی است.
- [ ] سیلوئت و برش لباس تغییر نکرده است.
- [ ] جای چاپ و گلدوزی درست است.
- [ ] دکمه، زیپ، ترمه و دوخت‌ها سر جای خود هستند.
- [ ] بافت پارچه طبیعی است و شبیه پلاستیک نیست.
- [ ] ترکیب‌بندی و کادر تمیز است.
- [ ] پس‌زمینه مزاحم نیست و لباس را نمی‌پوشاند.
- [ ] آناتومی بدن، دست‌ها و انگشت‌ها درست است (در حالت مدل).
- [ ] هیچ متن، واترمارک، لوگوی ناخواسته یا برچسب ساختگی وجود ندارد.
- [ ] لباس موضوع اصلی تصویر است.

## برچسب‌های خطا

هنگام رد کردن یک تصویر، دلیل را ثبت کنید:

- `wrong_color` — رنگ اشتباه
- `changed_design` — تغییر طرح یا جزئیات
- `missing_detail` — حذف شدن جزئیات
- `bad_anatomy` — آناتومی یا دست‌های غیرواقعی
- `poor_composition` — ترکیب‌بندی ضعیف
- `background_issue` — مشکل پس‌زمینه
- `artifacts` — لکه، شیء اضافه یا اثر هوش مصنوعی

## ثبت خطاها

برای هر خطا این موارد را بنویسید:

| تاریخ | نسخه پرامپت | حالت | برچسب خطا | توضیح کوتاه |
|---|---|---|---|---|
|  |  |  |  |  |

نسخه پرامپت در پایین هر کارت تاریخچه و در رکورد تولید ذخیره می‌شود. خطاها را بر اساس همان نسخه مقایسه کنید تا معلوم شود تغییر پرامپت بهتر شده یا بدتر.

## قاعده نهایی

- هر تصویر را قبل از انتشار بازبینی کنید.
- تصویر ردشده را با همان پرامپت منتشر نکنید؛ ورودی، صحنه یا مرجع را تغییر دهید.
- خروجی‌های مشکوک را برای بررسی نگه دارید، اما منتشر نکنید.
